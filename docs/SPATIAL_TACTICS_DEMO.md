# 断桥堡垒 · 空间战术整合 Demo

这是一场使用正式 CombatEngine、事件堆、ClashPool、规则目录和 Socket 会话的战斗。三名突击组成员从西侧推进，三名守军驻守东侧；中央断柱、沙袋和水域把移动、射击与团队配合串在同一战场。

## 启动

```powershell
pnpm demo:tactics
# 已经构建过时：
pnpm demo:tactics:start
```

默认地址为 `http://127.0.0.1:3001`，默认存档和凭据位于 `.demo-tactics/`。本机查看 `.demo-tactics/credentials.json` 获取主持凭据和玩家加入码。与旧 `pnpm demo` 的 3000 端口和 `.demo/` 存档分别使用；不需要推送 Prisma schema 或运行 seed。

可使用 `ELYSIAN_DEMO_HOST`、`ELYSIAN_DEMO_PORT`、`ELYSIAN_DEMO_DATA_DIR` 覆盖监听地址、端口和独立存档目录。LAN 连接使用启动时显示的主机局域网地址。

GM 登录后可直接点击「开始战术演练」独立控制双方，也可邀请三位玩家，分配先锋、游侠和术师。守军由 GM 操作。每个可行动角色必须提交动作或「等待 +5 Tick」，收齐后事件队列才推进；反应窗口可以逐一选择或由 GM 点击「全部放弃反应」。暂停、单步和 Tick 断点可用于观察投射物飞行及多动作同时生效。

## 同一场遭遇的演练路线

进入战斗后展开下方「行动与反应」，打开「空间战术演练」即可查看路线、角色部位耐久、装备、掩体和护卫状态。先选角色，再选动作；需要落点的动作直接点击地图格。Esc 或地图右键取消选择。

| 环节 | 操作与观察 |
| --- | --- |
| 掩体接敌 | 先锋沿中央空隙冲刺。墙柱和占位实体阻挡路径，水域增加移动耗时。游侠在西侧沙袋附近切换架枪、撩枪，对比弹道精度和落点偏移；离开沙袋后掩体状态消失。 |
| 弹道与越障 | 步枪直射产生飞行实体，到碰撞时才造成伤害。全掩体挡住低空直射，抛物爆弹越过低障碍；弹道上的第三方也可能被击中。 |
| 护卫协作 | 先锋靠近队友后部署护卫，让守军攻击被护卫者。相同阵营的多个护卫提供协作加成；失败可能付出韧性和击退代价。 |
| 通道封锁 | 在 4 距离内放置封锁区，观察金色区域。敌人从区域外进入时受伤，同方可穿过；18 Tick 后区域通过堆事件过期。 |
| 触及与侧翼 | 长枪有效距离 1–3，最短距离内挥空，极限距离减伤。贴身时弃长枪、换副武器再速击。绕到守卫背面背刺，然后让守卫转身比较伤害。 |
| 位移闪避 | 选择 2 距离内空地，争取在攻击窗口前完成位移。闪避是位置变化，范围伤害仍可能命中。 |
| 标签微避 | 下潜、小跳、侧闪在原地建立 3 Tick 生效窗口，分别匹配 HIGH、LOW、LINEAR。用要害重击、扇形扫荡、长枪突刺对比匹配效果；无标签爆炸不会被微避。 |
| 范围压制 | 抛射爆弹选择落点，落地圆形爆炸带伤害衰减与爆风阴影；扇形和线形攻击沿施放者朝向展开。地图标示几何覆盖，命中和掩体由服务器判断，友军也会受伤。 |
| 部位与终局 | 要害重击使用部位判定、暴击和单击上限；已破坏部位再次命中打空。其他损伤攻击直接扣生命。击倒一方全部角色后等待当前事件完成，保存结算，再重开演练。 |

行动卡显示前摇、收招、资源耗费和说明。装备长枪、步枪或副武器后才能使用对应攻击。治疗、恢复、引导及原有招架／打断反应仍可与空间战术组合。

## 实现边界

- 新战术由可选 `ActionTemplate.spatial` 数据定义，在正常动作 ACTIVE 阶段提交；没有通过前端计算伤害或 GM 瞬改替代玩家动作。
- 圆形落点通过动作事件传给真实投射物，爆炸发生在碰撞或抵达时。动作声明和投射物发射不提前扣除目标生命。
- 同 Tick 动作使用不可变组快照读取全部场景实体，再统一提交范围伤害、护卫、装备和朝向变更。
- 场景静态墙体和活掩体 PROP 提供移动／弹道障碍；角色在附近获取定向掩体，移动离开后清除。掩体 PROP 可以成为攻击目标。
- 演练路线是公开说明。实体、动作、日志和区域信息仍在服务端按接收者过滤。
- 服务重启支持保存的开局布局和已结算结果；任意 Tick 的精确崩溃续战、自动 NPC AI 和跨设备弱网性能认证不在本场景范围。

## 验证命令

```powershell
pnpm test:tactics
pnpm build
pnpm --filter @hard-vtt/frontend lint
pnpm test:tactics:browser
```

`test:tactics` 用隔离 runner 读取当前 TypeScript，临时 SQLite 不触碰开发库；覆盖真实空间动作、范围结算、投射物、三条 Socket 连接与界面渲染。浏览器脚本读取完整构建产物，使用临时存档，通过真实界面完成主持入场、姿态／护卫／转身和爆弹落点选择。浏览器证据保存在 `.tmp/spatial-tactics-browser/`。

上述为复现方式，实际运行结果以本次交付说明和本地测试报告为准。
