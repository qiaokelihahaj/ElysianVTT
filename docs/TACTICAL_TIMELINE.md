# 战术时间轴交互

时间轴位于地图上方，角色共享横向 Tick 刻度。阶段条宽度表示服务端提供的持续时间，优先级不影响宽度；同 Tick 的生效位置对齐。前摇、生效窗口、后摇以文字和不同填充区分，多击动作展开每次小前摇与生效窗口。

当前 Tick 指针随权威快照跳转，不用现实秒数模拟战斗推进。暂停、等待行动提交和等待反应有明确状态提示。待机角色保留轨道，方便比较所有可见角色的状态。

时间轴支持折叠、缩放、横向浏览与回到当前。查看动作详情或聚焦动作只改变本页的高亮，不切换操控角色、不发送战斗命令。GM 修改仍通过暂停后的裁决编辑入口完成，不提供容易误触的拖动改序。

显示内容以服务端按接收者过滤后的快照为准。未提交的本地目标选择不属于公共时间轴；短期结果只显示当前页面获准接收的日志。旧服务缺少权威阶段数据时应明确提示，不能用动作目录推算并冒充实际区间。

本次界面更新不需要数据库迁移。后端新增的时间轴数据在正常重启服务后生效；不要为了查看新界面强制重启正在进行的对局。
