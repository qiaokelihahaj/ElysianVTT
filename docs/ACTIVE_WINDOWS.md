# 动作生效窗口与地图指向

## 规则约定

一次攻击的生效窗口为半开区间 `[开始 Tick, 结束 Tick)`。前摇和后摇不结算这一击；窗口打开时检查目标，窗口内施放者或目标的位置发生变化时重新检查。每一击对每个目标最多进行一次命中结算，防御使伤害为零也不会恢复这次机会。越界时不消耗机会，窗口内重新进入可以首次命中，已经命中过则不会重复命中。

多重攻击采用「大前摇 →（小前摇 → 生效窗口）× 次数 → 后摇」，包括首击的小前摇。每一击有独立的命中记录。持续引导的维持消耗和停止后续脉冲规则独立保留。

模板通过可选 `activeWindowTicks` 启用单击窗口，或通过 `strikeSequence: { count, startupTicks, activeWindowTicks? }` 配置有限多击；`timeCost.startupTicks` 为大前摇，序列内的 `startupTicks` 为每击小前摇。Demo 近战窗口为 3 Tick，远程和治疗窗口为 1 Tick。未启用这些字段的旧模板保留原有动作路径。

实现由窗口边界、移动及 GM 位置调整等事件驱动，不逐 Tick 轮询。服务端负责距离与效果判断，同 Tick 的动作继续遵守优先级分组与同组快照提交；显示更新本身不触发伤害。

## 地图表现

实体关系箭头读取施放者和目标的最新同步坐标；移动箭头连接当前位置与当前计划落点。坐标变化时，端点、曲线及标签随角色一起更新。实体移除或失去可见性后不保留关系线。

「可以锁定」与「当前处于作用范围」是两件事。支持生效窗口的动作可提前锁定可见的范围外目标，界面明确提示「当前在范围外，生效窗口内进入才命中」；范围高亮仍只标示当前实际范围。最终命中由服务端在生效窗口中裁定。
